Brickwright for Roblox Studio

Insert your builds and GUIs straight into your game. No more copying scripts into the command bar.

  1. Download the plugin.
    Download Brickwright.rbxmx
  2. Install it. In Studio open the Plugins tab → Plugins Folder, drop Brickwright.rbxmx in, then restart Studio.
  3. Connect your account. Click the Brickwright button in the Plugins tab and paste your plugin code:

    Sign in first. Keep this code private — anyone with it can see your builds.

  4. Insert. Press Insert on any build (goes into Workspace) or GUI (goes into StarterGui). The first time, Studio asks to allow script injection and requests to brickwright.netlify.app — press Allow for both.

Your 40 newest builds from Studio and GUIs from the GUI Maker show up in the plugin. Inserts can be undone with Ctrl+Z.
